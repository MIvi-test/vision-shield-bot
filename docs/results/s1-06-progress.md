# S1-06: промежуточный результат Dev2

13 ноября 2026. Задача не закрыта; зависимость S1-07 остаётся на согласовании.

| Критерий S1-06 | Состояние |
| --- | --- |
| MAX-адаптер и `/start` | Есть локальный mock-адаптер на maxapi; реальные polling/webhook пока не подключены |
| Миграции | Есть Alembic-миграция PostgreSQL-inbox и cursor; доменных таблиц ещё нет |
| Согласие | Не реализовано; привязка к кампании/правилам согласуется |
| Фото и заявка awaiting_consent/validating | Определение фото есть; создание заявки и переходы ещё не реализованы |
| Повтор входного события | PostgreSQL-inbox не создаёт повторную запись или повторный запланированный ответ |
| Продвижение marker | Порция нормализованных событий и marker коммитятся вместе |
| Фото не скачивается | Соблюдается; URL и токены вложений в inbox не сохраняются |

Режим без БД оставлен как проверка связи. Новый режим запускается через
`apps/backend/run_inbox_bot.py`; настройки и миграции описаны в
[README Backend](../../apps/backend/README.md).

Проверены upgrade/downgrade и соответствие моделей миграциям, откат всей
порции при ошибке, повтор события, разные источники, конфликт marker,
восстановление committed pending-ответа, авария/ошибка отправки без слепого
повтора. Всего 33 теста проходят с отдельным PostgreSQL 18 на localhost.
В CI добавлен временный PostgreSQL-сервис для тех же тестов.

`sending` после аварии и `unknown` после ошибки требуют ручной сверки с
эмулятором, не переотправляются автоматически. Надёжная доставка через
RabbitMQ/outbox (S1-17) и API панели (S1-18) не объявляются выполненными.
Локальный mock-режим не предназначен для реальных заявок или production.

После согласования S1-07: миграции пользователей/кампаний/согласий/заявок,
бизнес-переходы и аудит вместе с inbox, затем отдельная реализация S1-17.
Для файлового пути потребуется расширение входных метаданных вложения:
нынешний режим сохраняет лишь признак фото и текст, не ссылку для скачивания.
