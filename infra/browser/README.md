# Браузерная приёмка S1-16

Playwright 1.58.2 и его транзитивные зависимости фиксируются package-lock.json.
Chromium запускается в официальном образе с digest, указанным в smoke_compose.py.
Это изолированные тестовые зависимости, не часть production-панели.

Запуск из корня: `python infra/scripts/smoke_compose.py --sprint-one --browser`.
Скрипт поднимает отдельный Compose-проект, создаёт синтетический аккаунт,
проверяет реальный API и UI, затем удаляет только свои контейнеры/тома.
PANEL_PASSWORD передаётся через окружение, не через аргументы. Скрипт не
сохраняет traces, cookies или storageState; только безопасные скриншоты.

Проверки: ошибочный/успешный вход, три настоящие заявки, карточка/согласие,
фильтр, восстановление после reload, ширина 375 px, logout и reload после него.
Pagination проверяется через настоящий API отдельно в том же прогоне.
