# Политики модерации

Машиночитаемая часть [политики v0](../../../docs/policy.md).

| Файл | Схема | Что это |
| --- | --- | --- |
| `campaigns/nature-v0.json` | `campaign-policy.schema.json` | Демо-кампания «Природа»: тема, шаблоны CV, запреты, режим, пороги |
| `media-profile-v0.json` | `media-profile.schema.json` | Форматы, лимиты и параметры очистки для media worker. Общие для всех кампаний |
| `reason-codes.json` | `reason-codes.schema.json` | Коды причин, их эффект и тексты для автора |

Тему кампании может менять маркетинг. Media-профиль и коды причин меняет только Dev3: это граница защиты и общий словарь команды.

## Как сменить тему

- **Новая тема** — новая кампания: `campaigns/<slug>-v0.json`. У неё свой учёт дублей.
- **Правка той же темы** (фразы, описание) — новая версия: `campaigns/<slug>-v<N+1>.json`.

Порядок:

1. Скопировать существующий файл кампании, поменять `policy_version`, `campaign_slug`, `theme` и фразы `cv.topic`. Фразы для англоязычных моделей пишутся на английском.
2. Блок `cv.prohibited` скопировать без изменений: запреты общие для всех тем.
3. Оставить `mode: "manual"` и `thresholds.calibrated: false`. Пороги одной темы на другую не переносятся. `auto` включается только новой версией после оценки качества на данных этой темы ([policy.md §7](../../../docs/policy.md#7-критерии-приёмки-качества-для-s3-02)).
4. Проверить: `uv run pytest tests/test_moderation_policy.py`.
5. Открыть PR, ревью Dev3. Если изменились правила, на которые соглашается автор, согласовать с Dev2 новую версию текста правил: бот запросит согласие заново.

Версию со статусом `approved` не редактировать — только выпускать следующую.
