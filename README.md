# vision-shield-bot

Тематическая фотолента в MAX с автоматической и ручной модерацией.

Архитектура — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md),
задачи — [docs/sprints.md](docs/sprints.md), роли — [docs/team.md](docs/team.md),
история изменений — [CHANGELOG.md](CHANGELOG.md).

Выполненная Dev1 работа: подготовка репозитория, CI и Python-инструменты,
проверка реального MAX с обезличенными ответами и эмулятор MAX v0 с тестами.
Результаты S1-01, S1-02, S1-04 и S1-05 сохранены в плане с авторством и PR.
Следующие этапы: запускаемый приём заявок и панель → полная ручная модерация
с публикацией → MVP с автоматической модерацией. После MVP — оставшиеся
функции постановки и проверка условий ограниченной эксплуатации.

Подготовка локальной конфигурации:

```bash
cp .env.example .env
```

`.env` исключён из Git. Токены и пароли заполняются локально.
Эмулятор MAX можно запустить отдельно по
[инструкции](apps/max-emulator/README.md). Backend и Compose пока отсутствуют;
запуск общего стенда появится в S1-03.

Изменения вносим отдельной веткой через PR с минимум одним одобрением другого
участника команды. Ревьюера выбираем вручную; решение о CODEOWNERS отложено.
Настройка защиты `main` описана в [CONTRIBUTING.md](CONTRIBUTING.md).
