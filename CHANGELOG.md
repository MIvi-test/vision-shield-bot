## 2026-10-25

### Добавлено

- **S1-05, Dev1 — Илья:** реализован самостоятельный MAX-эмулятор v0 на
  FastAPI/Uvicorn. Поддержаны polling текста и фото, маркеры и повторное чтение,
  раздача синтетической PNG, сохранение текстовых ответов, служебный API для
  тестов и Swagger UI. Данные хранятся в памяти процесса.
- Добавлены 18 тестов эмулятора, включая проверку через настоящий `maxapi 1.2.3`
  по HTTP на случайном localhost-порту: получение событий, скачивание байтов
  изображения и отправка ответов. Запуск описан в
  [README эмулятора](apps/max-emulator/README.md).
- **Развитие S1-02, Dev1 — Илья:** проверка типов через ty подключена локально
  и в CI; настроены корни импортов и обновлены фиксированные зависимости.

Подтверждения: PR #7 (`5a4ac7a`, эмулятор и 18 проходящих тестов),
PR #8 (`6768066`, ty).

## 2026-10-24

### Добавлено

- **S1-02, Dev1 — Илья:** CI запускает Ruff, проверку форматирования и pytest,
  предусматривает сборку React/TypeScript-панели после появления её manifest.
  Настроены Python 3.14, `pyproject.toml` и установка по `uv.lock`. Отсутствующие
  на тот момент тесты и фронтенд явно отмечаются как пропущенные этапы.
- **S1-04, Dev1 — Илья:** выполнено исследование реального MAX через
  `maxapi 1.2.3`. Проверены polling, текст, фото/файл, скачивание, загрузка,
  публикация, чтение сообщений, callback-кнопки, удаление и повторное удаление.
- Сохранены [протокол MAX](docs/results/max-check.md) и
  [22 обезличенных ответа API](packages/contracts/max/README.md) для разработки
  адаптера, эмулятора и контрактных тестов; обновлены контракты и риски.

### Уточнено по результатам проверки

- MAX может преобразовывать изображения: наблюдались WEBP на входе и JPEG
  после публикации PNG. MIME и расширение не определяют допустимость файла.
- Нативные реакции не обнаружены в проверенных ответах и polling-событиях;
  callback-кнопки подтверждены. Источник рейтинга требует отдельного согласования.
- Ссылки на вложения скачивались без токена; наблюдаемое время доступности
  не является гарантией TTL. Такие ссылки не сохраняются в публичных материалах.

Подтверждения: PR #5 (`5287690`, CI), PR #6 (`f30599b`, исследование MAX).
