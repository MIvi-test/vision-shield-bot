# Changelog

История значимых изменений проекта. Записи сгруппированы по датам Git-коммитов;
это не номера и даты релизов. Новые изменения сначала добавляются в `Unreleased`.
Планы и критерии готовности ведутся в [docs/sprints.md](docs/sprints.md).

## Unreleased

### Исправлено

- Swagger эмулятора использует схему авторизации и кнопку Authorize вместо
  обычного параметра Authorization, который Swagger не отправлял.
  Контракт SDK/curl и ответы 401 сохранены.

### Добавлено

- Dev2: независимая часть S1-06 — PostgreSQL-inbox и polling-cursor,
  миграция Alembic, отдельный локальный бот с транзакционным сохранением
  порции и маркера, дедупликацией и учётом неизвестного исхода отправки.
  PostgreSQL-тесты миграций, отката, восстановления и отправки подключены
  к CI. Правила согласий, заявки и S1-17 остаются дальнейшей работой.

- Dev2: локальный Backend-бот на maxapi с ответами `/start`, `/help`,
  на текст и фото без скачивания, с ограниченной дедупликацией в памяти.
  Добавлен SDK/HTTP-тест с эмулятором; приём заявок и БД остаются дальнейшей
  работой. maxapi перенесён из dev в основные зависимости без смены версии.

- Dev2: начальный HTTP-каркас Backend с liveness и инструкцией запуска.
  БД и API панели ещё не реализованы.

- Этот changelog с историей разработки и ссылками из README и плана спринтов.
- Security workflow: CodeQL `security-extended` для Python и GitHub Actions,
  аудит всего `uv.lock` через `uv audit --locked` на PR, push в `main`/`develop`,
  еженедельно и вручную. Ошибки аудита не скрываются.
- Инструкция обязательных checks и Code scanning merge protection для
  `main` и `develop`; фактическая проверка блокировки merge остаётся S1-19.

### Изменено

- Обновлены Pydantic до 2.14.2, pytest до 9.2.0, Ruff до 0.17.3 и ty до 0.0.95;
  пересобран `uv.lock` с обновлением совместимых транзитивных зависимостей:
  anyio 4.16.0, opentelemetry-api 1.45.2, pydantic-core 2.50.2.
- uv в CI обновлён до 0.13.6; checkout, setup-python, setup-node и CodeQL
  закреплены полными SHA актуальных стабильных релизов. Gitleaks 8.30.1
  продолжает проверять каждый push во все ветки/теги и PR, без фильтров путей
  и отмены предыдущего запуска.

### Уточнено по результатам проверки

- MAX может преобразовывать изображения: наблюдались WEBP на входе и JPEG
  после публикации PNG. MIME и расширение не определяют допустимость файла.
- Нативные реакции не обнаружены в проверенных ответах и polling-событиях;
  callback-кнопки подтверждены. Источник рейтинга требует отдельного согласования.
- Ссылки на вложения скачивались без токена; наблюдаемое время доступности
  не является гарантией TTL. Такие ссылки не сохраняются в публичных материалах.

Подтверждения: PR #5 (`5287690`, CI), PR #6 (`f30599b`, исследование MAX).
