# Приложения

Компоненты создаются по мере реализации задач:

| Каталог | Назначение | Владелец |
| --- | --- | --- |
| `backend/` | API, MAX-адаптер, доменная логика и фоновые процессы | Dev2 |
| `max-emulator/` | Эмулятор внешнего MAX API и тестовые сообщения | Dev1 |
| `media-worker/` | Проверка и очистка изображений | Dev2 |
| `cv-worker/` | Анализ изображений | Dev3 |
| `moderator-ui/` | Панель модератора | Dev4 |

Архитектура и границы компонентов — в [ARCHITECTURE.md](../docs/ARCHITECTURE.md).
